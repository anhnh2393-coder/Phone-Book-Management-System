# Project Description

## Phone Book Management System

The Phone Book Management System is a software system that allows users to manage contact information in an organized way. The system provides basic functions such as adding, viewing, searching, updating, and deleting contacts.

### Objectives
- Store contact information efficiently.
- Make it easy for users to find a specific contact.
- Allow users to update outdated information.
- Allow users to remove unnecessary contacts.
- Provide a simple and user-friendly contact management process.

### Contact Information
Each contact may contain:
- Contact ID
- Full Name
- Phone Number
- Email Address
- Address
