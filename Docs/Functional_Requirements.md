# Functional Requirements

## FR01 - Add Contact
The user can add a new contact to the phone book.

**Input:**
- Full name
- Phone number
- Email
- Address

**Output:**
- A new contact is successfully saved.

## FR02 - View Contact List
The user can view all contacts stored in the system.

## FR03 - Search Contact
The user can search for a contact using information such as:
- Name
- Phone number

## FR04 - Update Contact
The user can modify existing contact information.

## FR05 - Delete Contact
The user can remove an existing contact from the phone book.

## FR06 - View Contact Details
The user can select a contact and view detailed information.
