# Functional Requirements

## FR01 - Add Contact
The user can add a new contact to the phone book.

**Input:**
- Full name
- Phone number
- Email
- Address

**Output:**
- A new contact is successfully saved.

**FR02 – View Contact:**
Users can view the contact list and detailed information of a selected contact.

**FR03 – Update Contact:**
Users can edit and update information of an existing contact.

**FR04 – Delete Contact:**
Users can delete a contact. The system asks for confirmation before deletion.

**FR05 – Search Contact:**
Users can search for contacts by name, phone number, email, or group.

**FR06 – Manage Groups:**
Users can create, view, update, and delete contact groups such as Family,
Friends, Work, and School.

**FR07 – Assign Contact to Group:**
Users can assign or change a contact's group to organize contacts more easily.

**FR08 – Validate Information:**
The system checks required fields and validates phone number and email formats
before saving or updating a contact.

**FR09 – Check Duplicate Contact:**
The system checks for duplicate phone numbers before adding a new contact.

**FR10 – View Statistics:**
Users can view basic statistics, such as the total number of contacts and
the number of contacts in each group.

**FR11 – Data Management:**
The system automatically updates stored data after adding, editing, or
deleting contacts.

**FR12 – Exit System:**
Users can safely exit the system after completing their operations.
